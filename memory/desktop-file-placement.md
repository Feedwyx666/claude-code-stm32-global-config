**在桌面（Desktop）新建文件或文件夹前必须谨慎——用户的桌面图标是自动排列/按名称排序的，新增项目一旦排在前面，后面所有图标会整体后移，用户精心摆放的布局全部错位。**

**Why:** 2026-08-08 我按用户要求把配置包放到桌面，新建了 `Claude配置部署包\`。该名称以 `C` 开头排序靠前，插入后用户「所有图标全部往后移了 全错位了」。用户明确要求「下次不要把文件插到桌面第一个图标」。

**How to apply:**
- **默认不往桌面直接新建东西**。需要给用户一个方便取用的位置时，优先建议其他位置（如 `Documents\`、某个已有文件夹、或原地不动只告诉路径）。
- 用户明确要求放桌面时，**先问清放在哪个位置/用什么名字**，不要自己拍板。可提示："放桌面会让图标重排，要不要放到 XXX，或者用一个排序靠后的名字？"
- 命名影响排序：Windows 中文环境下，**拉丁字母开头一般排在中文名之前**，所以 `zz_` 之类前缀仍会挤到中文命名的图标前面。**没有可靠的"一定排最后"的名字**，最稳妥的办法就是不放桌面。
- 已经造成错位时：**移走或删掉该项目通常能恢复原顺序**（自动排列下顺序由排序规则决定，移除后其余图标会自动回位）。但图标位置无法手工"还原"，只能靠移除新增项。
- 同理适用于用户桌面上的批量操作（解压、生成日志、临时文件），一律避免落在桌面。
- 本机桌面被重定向到 `D:\Users\Y\Desktop`（不在 C 盘），判断路径时注意。
- 参见 [[confirm-before-edits]]（改动前先确认）、[[ensure-launch-script]]。
