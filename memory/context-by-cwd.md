根据打开 Claude 时所在的**工作目录/上下文**判断用户当前的使用目的，不要默认所有对话都与 STM32 开发有关。

**Why:** 用户说「如果我没有在一个keil工程文件夹内打开你，或许我在学习c语言或者甚至与编程无关。此时你不用把问题都引到stm32开发上」。
**How to apply:**
- 在 Keil 工程文件夹（含 `.uvprojx` 等工程文件）内 → 大概率是 STM32 开发场景，可关联 [[user-learning-stm32]]。
- 不在 Keil 工程文件夹 → 可能是学 C 语言、学其他语言、或与编程无关的任务；**不要硬把话题引到 STM32**，按用户实际问的内容作答。
- 工作目录只是第一个线索，应结合提问内容综合判断。
